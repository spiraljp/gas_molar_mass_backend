## Описание статусов

- `опубликован` — газ отображается на страницах ленты и плитки.
- `черновик` — газ отображается только на странице добавления.
- `удален` — газ не отображается в интерфейсе.

## Планируемая фильтрация

На странице плитки будет использоваться серверная фильтрация по молярной массе газа.

Пример параметра запроса: `/gases?max_molar_mass=40`

При указанном параметре отображаются только опубликованные газы, у которых молярная масса меньше или равна заданному значению.
