# Gas Molar Mass Backend

Репозиторий бэкенда для курсового проекта по дисциплине РИП.

## Тема

Расчет молярной массы газа.

## Предметная область

Приложение представляет собой заявочную систему для расчета молярной массы газа.

Услуги — это различные газы с известными молярными массами и физическими свойствами.

Заявка — это расчет молярной массы неизвестного газа по данным о его массе и объеме при нормальных условиях. Также в заявке может указываться смесь из двух выбранных газов с заданными концентрациями.

## Планируемый стек

- Python
- FastAPI
- Jinja2 templates
- PostgreSQL
- SQLAlchemy / SQLModel
- MinIO
- Redis

## Лабораторная работа 1

В рамках первой лабораторной работы требуется:

- выбрать тему на весь курс;
- разработать дизайн трех мобильных страниц в Figma;
- развернуть MinIO для хранения изображений и видео газов;
- подготовить базовую шаблонизацию на стороне бэкенда;
- реализовать одну коллекцию данных без использования базы данных;
- реализовать серверную фильтрацию.

## Страницы лабораторной работы 1

- Лента: вертикальное видео газа и информация о нем.
- Добавление: отображение черновика газа в виде формы без сохранения.
- Плитка: список карточек газов с серверной фильтрацией.
